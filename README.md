# Swiggy – Food Delivery Backend System

A REST API-based food delivery backend application inspired by Swiggy. Developed using Node.js, Express.js and MongoDB as part of the Backend Developer Internship at ElevanceSkills.

## 🚀 Project Overview

This project provides backend functionality for a food delivery platform, including user authentication, restaurant management, menu operations, cart management, order processing, delivery partner assignment and notifications.

## 🛠️ Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt
- Postman
- Git & GitHub
- Render

## ✨ Key Features

- User registration and login.
- JWT-based authentication and authorization.
- Restaurant and menu management.
- Add items to cart and retrieve cart details.
- Order placement and management.
- Delivery partner management.
- Order status updates and notifications.
- Admin management functionality.

## 🎯 Internship Tasks

The following six features were implemented as part of the internship assignment:

1. **Fraud Detection & Order Validation** – Detects suspicious ordering activities using risk scores and admin review functionality.
2. **Restaurant Search & Filters** – Supports restaurant search, cuisine, vegetarian, rating and other filters.
3. **Surge Pricing** – Implements additional pricing during peak hours and specified periods.
4. **Delivery Partner Assignment** – Assigns available delivery partners based on city, workload and rating.
5. **Order Status & Notifications** – Updates order status and generates customer notifications.
6. **Restaurant Recommendations** – Provides restaurant recommendations through a dedicated API.

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/PraptiTanisha/Swiggy-Backend-Internship.git
```

**2. Open the project directory**

```bash
cd Swiggy-Backend-Internship
```

**3. Install dependencies**

```bash
npm install
```

**4. Configure environment variables**

Create a local `.env` file and configure the required environment variables on your machine.

**5. Run the development server**

```bash
npm run dev
```

**6. Run the production server**

```bash
npm start
```
